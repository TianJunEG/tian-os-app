## DATA FIELDS COLLECTED

For each school, the following information has been compiled:

1. **School Name** - Official MOE school name
2. **Region/District** - Specific planning area
3. **Zone Code** - Geographic zone classification
4. **Address** - Full street address
5. **Postal Code** - Singapore postal code (S######)
6. **Email Address** - Official school email (school_name@moe.edu.sg)
7. **Phone Number** - School main line (Singapore landline)
8. **Website URL** - School website or MOE subdomain
9. **School Type** - Classification (Government/Aided/Special Ed)
