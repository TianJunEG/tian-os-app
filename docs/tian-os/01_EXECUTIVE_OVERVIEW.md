# Tian OS Executive Overview

**Status:** Working documentation  
**Last updated:** June 8, 2026  
**Current safe product scope:** MathPath Fractions Intervention Pilot

---

## 1. What Tian OS Is

Tian OS is an AI-native education operating system designed to help students improve through targeted intervention rather than generic practice.

The current product focus is **MathPath Fractions Intervention**.

The core promise is:

> Identify what the child misunderstood, teach that specific gap, verify improvement, and show the evidence clearly to adults.

Tian OS is not intended to be only a question bank, worksheet generator, or learning management system. It is being built as an evidence-first intervention platform.

---

## 2. Current Safe Positioning

The current safe external positioning is:

> **Tian OS MathPath — Fractions Intervention Pilot**

This means Tian OS can currently be discussed as a controlled pilot focused on identifying and addressing Fractions weaknesses.

Do not currently claim:

- Full P1–P6 MathPath readiness
- Complete Singapore Math coverage
- School-ready intervention platform
- Full subject coverage
- Fully validated mastery detection
- Guaranteed improvement
- That the system identifies all weak areas

Approved claim style:

- “This pilot focuses on Fractions intervention.”
- “The system identifies evidence of Fractions weaknesses and recommends targeted practice.”
- “The system tracks improvement where diagnostic, recovery, and recheck evidence exists.”
- “Reports are designed to show what improved, what still needs work, and what to do next.”

---

## 3. Why Tian OS Exists

Many learning platforms can tell whether a child got an answer right or wrong.

The bigger educational problem is:

- Why did the child get it wrong?
- Was it a careless mistake, a method error, or a conceptual misconception?
- What should the child do next?
- Did the intervention actually help?
- Can the parent, tutor, or teacher see trustworthy evidence?

Tian OS is being built to close this gap.

The platform should not reward activity alone. Completing questions, clicking “reviewed”, or viewing a page should not automatically count as mastery.

Learning evidence should come from:

- correction
- reflection
- guided practice
- independent practice
- mastery checks
- rechecks
- working evidence
- improvement over time
