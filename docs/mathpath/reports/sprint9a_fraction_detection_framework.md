# Sprint 9A Fraction Detection Framework

Status: Completed

## Supported Candidate Forms

- proper fractions, such as `1/2`
- improper fractions, such as `7/4`
- mixed numbers, such as `2 1/3`

## Output

Detected fractions are stored with:

- original value
- normalised value
- representation type
- confidence score

## Limitation

Vertical handwritten fractions require OCR/stroke recognition quality from future processing. This sprint creates the data structure and candidate pathway.
