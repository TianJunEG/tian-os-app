# Sprint 8 Critical Fix List

## Critical

Status: Completed

- Diagnostic insights lacked a structured intervention layer.
- Assignments could not store why they were assigned.
- Completion tracking did not include skipped, expired, started, or timestamped state changes.
- There was no deterministic way to create one-click assignment options from an insight.

## High

Status: Completed

- No reusable assignment templates.
- No reusable intervention playbooks.
- Teacher class assignments could not carry intervention metadata.
- Help requests could not create an intervention recommendation.
- Intervention effectiveness could not be calculated from before/after signals.

## Medium

Status: Partial

- UI surfaces need richer rendering of priority, next action, and playbook labels.
- Notification delivery is not yet implemented; notification event generation is ready.
- Mobile screenshot verification is still needed.

## Low

Status: Partial

- Future AI study-plan generation is not built, but `aiReadyContext` fields are now available.
