# Sprint 9B Failure Point Framework

Status: Completed

## Supported Failure Types

- first incorrect step
- last correct step
- missing step
- abandoned step
- final-answer-only mistake
- none detected

## Principle

The engine suggests failure points with confidence. It does not claim certainty without human verification.

## Human Loop

Tutors, teachers, and admins can accept, edit, or reject procedure suggestions.
