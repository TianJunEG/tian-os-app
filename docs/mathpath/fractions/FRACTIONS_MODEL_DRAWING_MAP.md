# Fractions Model Drawing Map

Status: reference map  
Scope: Fraction word problems and heuristics

## Purpose

This document classifies fraction skills that should be supported by Tian OS Model Drawing / Heuristics. It is intended for future diagnostic, remediation, working-evidence, parent/tutor, and teacher-mode planning.

The model classifications are based on the uploaded P3-P6 fraction reference PDFs and the existing `F001`-`F026` audit structure. They are not runtime question content.

## 1. Part-whole model

### Description

A single whole is split into known and unknown parts. This is the earliest model type and should be taught before multi-step fraction-of-remainder problems.

### Linked micro-skills

- FR5.05 Draw a part-whole bar model
- FR6.02 Identify the whole, part, and remainder
- FR6.03 Solve one-step part-whole fraction word problems
- FR6.04 Solve one-step fraction-of-quantity word problems

### Common errors

- Student uses the wrong whole.
- Student makes unequal units.
- Student treats part count as denominator without checking total parts.
- Student gives the part asked for but ignores the requested answer form.

### Remediation approach

Ask the student to label:

1. What is the whole?
2. What parts are known?
3. What part is unknown?
4. What unit or quantity does the answer need?

### Original Tian OS template examples

- A class has a total number of students. A fraction joined an activity. How many did not join?
- A length of ribbon is split into two parts. One part is given. Find the other part.
- A group has two categories. Find the fraction that belongs to one category.

## 2. Remainder model

### Description

The original whole is reduced by one or more events, and the student must reason about what is left.

### Linked micro-skills

- FR5.06 Draw a remainder bar model
- FR5.07 Subdivide a remainder in a bar model
- FR6.05 Solve remainder-after-giving-away problems
- FR6.09 Solve fraction-of-remainder problems

### Common errors

- Student applies a later fraction to the original whole instead of the remainder.
- Student does not label the remainder before using it.
- Student stops after finding the amount used or sold.
- Student ignores the final question and reports the wrong part.

### Remediation approach

Use a two-row model:

```text
Original whole
→ first event
→ remainder
→ second event applied to remainder
→ final remainder or target part
```

### Original Tian OS template examples

- A child spent a fraction of money, then spent a fraction of the remainder. Find the amount left.
- A baker sold a fraction of cakes in the morning, then a fraction of the remainder. Find the original number.
- A roll of string was used in two stages. Find the original length from the amount left.

## 3. Comparison model

### Description

Two or more quantities are compared by difference, ratio, or fractional relationship.

### Linked micro-skills

- FR6.06 Solve comparison fraction word problems
- FR7.05 Multi-topic fraction problem solving

### Common errors

- Student does not align bars to show the difference.
- Student confuses difference with total.
- Student treats `more than` as an addition instruction without finding the unit first.
- Student compares numerator or denominator only.

### Remediation approach

Require the student to draw two aligned bars and label:

- larger amount,
- smaller amount,
- difference,
- unit value,
- required target.

### Original Tian OS template examples

- There are more dogs than cats. A fraction of the animals are dogs. Find the total.
- One person has a fraction of another person's savings. Find their total savings.
- Two categories differ by a known amount. Find the original total.

## 4. Before-after model

### Description

The student reconstructs or tracks a quantity before and after spending, receiving, selling, giving away, or adding.

### Linked micro-skills

- FR6.10 Solve work-backwards fraction problems
- FR6.11 Solve before-after fraction problems
- FR7.05 Multi-topic fraction problem solving

### Common errors

- Student works forward when the question requires working backward.
- Student confuses final amount with original amount.
- Student does not convert known final units back to original units.
- Student ignores fixed additions or subtractions.

### Remediation approach

Use arrows and labels:

```text
At first → change 1 → remainder → change 2 → final amount
```

Then work backwards from the final amount where needed.

### Original Tian OS template examples

- A student spent a fraction of money and had a known amount left. Find the amount at first.
- A shop sold some items in the morning and afternoon, then had a known number left. Find the original number.
- A child used a fixed amount and a fraction of the remainder. Find the original amount.

## 5. Transfer/change model

### Description

A quantity is moved, used, sold, given, eaten, poured, or transferred between states or people.

### Linked micro-skills

- FR6.05 Solve remainder-after-giving-away problems
- FR6.08 Solve two-step fraction sequence problems
- FR6.11 Solve before-after fraction problems

### Common errors

- Student ignores one transfer.
- Student subtracts from the wrong quantity.
- Student calculates the transferred amount but not the final amount.
- Student misses words like `each`, `left`, `remaining`, and `altogether`.

### Remediation approach

Have the student underline action words and label each action as add, subtract, multiply, or divide.

### Original Tian OS template examples

- Someone had a quantity, used some, then gave away some. Find what was left.
- A container held liquid, some was poured out, then the rest was shared.
- A person spent money on several items and had some left.

## 6. Repeated quantity model

### Description

A quantity is repeated in equal groups, intervals, pieces, cups, containers, or multiples.

### Linked micro-skills

- FR6.08 Solve two-step fraction sequence problems
- FR6.12 Check whether final answer matches the question
- FR7.05 Multi-topic fraction problem solving

### Common errors

- Student finds number of gaps but not number of objects.
- Student rounds in the wrong direction.
- Student treats a partial group as a full completed group when the context does not allow it.
- Student ignores the unit size.

### Remediation approach

Ask: are we counting groups, gaps, full containers, or required containers? Then decide whether to round up, round down, or keep a fraction.

### Original Tian OS template examples

- A road has lights placed at equal intervals. Find number of lights including both ends.
- A liquid must be poured into containers of equal capacity. Find the smallest number of containers.
- A length is cut into pieces. Find the greatest number of complete pieces.

## 7. Fraction-of-remainder model

### Description

A fraction is applied to what remains after a previous action. This is a major source of P4-P6 fraction word-problem errors.

### Linked micro-skills

- FR5.07 Subdivide a remainder in a bar model
- FR5.08 Use branching/tree method for fraction-of-remainder problems
- FR6.09 Solve fraction-of-remainder problems

### Common errors

- Student applies all fractions to the original whole.
- Student does not create a new remainder after the first action.
- Student adds denominators or subtracts fractions without respecting sequence.
- Student misses that the second fraction has a different whole.

### Remediation approach

Use a branching or staged bar:

```text
Original whole
- first fraction of original
= remainder
- second fraction of remainder
= final amount / target
```

### Original Tian OS template examples

- A child spent a fraction of money, then a fraction of the remainder. Find the amount at first.
- A baker sold a fraction of pies, then a fraction of the remaining pies. Find how many were baked.
- A student used a fraction of string, then a fraction of what was left. Find the leftover length.

## 8. Branching/tree model

### Description

A sequential structure where each branch shows what happens to part of a total or remainder.

### Linked micro-skills

- FR5.08 Use branching/tree method for fraction-of-remainder problems
- FR6.09 Solve fraction-of-remainder problems
- FR6.10 Solve work-backwards fraction problems

### Common errors

- Student cannot track which branch is being subdivided.
- Student loses the original whole.
- Student cannot reverse a branch when working backwards.
- Student does not connect a known amount to a unit.

### Remediation approach

Make the student draw a tree before calculating:

```text
Total
├─ used/spent/given
└─ remainder
   ├─ second event
   └─ left
```

### Original Tian OS template examples

- Total money splits into spent and remaining, then remaining splits again.
- A group is divided into one category and remaining categories, then one remaining category is subdivided.
- A known leftover branch is used to reconstruct the original total.

## 9. Simultaneous quantities / units model

### Description

Different groups have different fractional changes. The solution requires assigning different unit values and linking them through a total or remaining condition.

### Linked micro-skills

- FR7.05 Multi-topic fraction problem solving
- FR7.04 Method-mark fraction working

### Common errors

- Student assumes boys and girls, or two different categories, have the same unit size.
- Student combines unlike units too early.
- Student fails to define each unit clearly.
- Student uses one denominator for all groups.

### Remediation approach

Use separate units for each group:

```text
UB = one unit of group B
UG = one unit of group G
```

Then form equations using the remaining and total relationships.

### Original Tian OS template examples

- A fraction of boys and a different fraction of girls left a place. Given total and remaining, find one original group.
- Different groups have different remaining fractions after an event.
- Two quantities are connected by a total and separate fractional changes.

## 10. Ratio-linked fraction model

### Description

Fractions are combined with ratio, area, or percentage relationships. This is an advanced P6/exam-style model.

### Linked micro-skills

- FR7.05 Multi-topic fraction problem solving
- FR7.03 Exam-style two-mark fraction items
- FR7.04 Method-mark fraction working

### Common errors

- Student treats shaded fraction as the full area.
- Student mixes ratio units with fraction denominators.
- Student does not convert all relationships to common units.
- Student loses the target order in the final ratio.

### Remediation approach

Convert every relationship into comparable units, then simplify the final ratio.

### Original Tian OS template examples

- A diagram combines a circle, square, and rectangle with shaded fractions and ratio relationships.
- A shape-area problem gives fractional shaded parts and asks for a ratio of total areas.
- A multi-topic problem links fractions, percentages, and ratio.

## Working evidence expectations

For model-drawing skills, Tian OS should expect the student to show at least one of:

- labelled bar model,
- correctly subdivided units,
- unit-value calculation,
- branch/tree diagram,
- comparison bars,
- before-after timeline,
- equations with defined units.

A correct final answer without working should not be treated as full evidence for model-drawing mastery.

## Implementation notes

- Model-drawing skills should be assignable as a separate practice module.
- Student working should be saved and surfaced to parent/tutor/teacher dashboards.
- Adult review should show the likely model type and the step where the student broke down.
- Future question generators should tag generated questions with `modelDrawing.required` and `modelDrawing.modelTypes`.
