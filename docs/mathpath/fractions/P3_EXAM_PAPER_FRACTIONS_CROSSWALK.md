## Purpose

This document maps P3 exam fractions question patterns to MathPath micro-skills and question families. It captures the frequency, difficulty, and format of real exam questions to guide question family design and skill coverage validation.

## Key Finding: Fractions Curriculum Timing

| Exam type | Term | Fractions present? |
|---|---|---|
| CA1 / WA1 | Term 1 | No (whole numbers only) |
| SA1 / WA2 | Term 2 | Varies (some schools start fractions) |
| WA3 | Term 3 | Yes (fractions-heavy) |
| EOY / SA2 | Term 4 | Yes (fractions always tested) |

CA1 and WA1 papers (Term 1) have **zero fractions questions**. Fractions appear consistently from Term 3 WA onwards and in all EOY papers.

## Implementation Notes

- Every new question family should include exam-style MCQ and SAQ format variants.
- "Shade more to reach target fraction" questions should use varied figure types (strips, grids, composite shapes).
- Number line questions should include both single-line (read one fraction) and dual-line (read two, then operate) variants.
- Composite figure questions should include: identical triangles, identical rectangles, mixed subdivisions.
- Simplest form should be tested both as standalone and as required finish step in multi-step questions.
- Word problems at P3 level focus on simple part-whole remainder reasoning (1 - fraction spent = fraction left).
- Same-numerator ordering (e.g. 5/9, 5/6, 5/7) is a distinct sub-pattern that tests inverse denominator logic.
- Missing-fraction-in-equation questions range from simple complement (? + a = 1) to reverse subtraction (a - ? = b).
