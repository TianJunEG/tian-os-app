# Tian OS Fractions I Reference Map

Created: 2026-06-07

Source use note: this map is based on the broad skill progression visible in the uploaded Fractions I PDF. Tian OS wording, templates, remediation notes, and parent/tutor explanations below are original and should not copy source platform wording or diagrams.

## Scope

Fractions I is treated as a bridge unit for students who can read simple fractions and are now moving into numbers greater than one whole. The Tian OS sequence is organized into 12 internal skills:

- Mixed-number meaning and simplification: `FR-MIX-01` to `FR-MIX-04`
- Improper-fraction meaning and conversion: `FR-IMP-01` to `FR-IMP-04`
- Comparison and ordering: `FR-CMP-01` to `FR-CMP-04`

## Skill Entries

### FR-MIX-01 - Understand Mixed Numbers as Wholes Plus Parts

| Field | Reference |
| --- | --- |
| Source skill focus summary | Interprets amounts greater than one whole using whole units and equal fractional parts. |
| Tian OS skill name | Understand Mixed Numbers as Wholes Plus Parts |
| Concept tested | Student identifies the whole-number part and fractional part of a mixed number and explains what each part represents. |
| Prerequisite | Recognize unit fractions, denominators as equal parts, and one whole. |
| Question template types | Match mixed number to shaded model; identify whole and fractional parts; count complete wholes plus remaining parts; choose the mixed number for a real-world quantity. |
| Common misconceptions | Treats the numerator as the number of wholes; ignores the whole-number part; reads `2 1/3` as `2/3`; assumes the denominator counts all objects instead of parts per whole. |
| Remediation strategy | Rebuild the number from physical or drawn wholes: first count complete wholes, then name the leftover equal parts. Ask the student to say "whole count, then part count." |
| Recheck pattern | Give a new model with complete wholes and one partial whole; ask for the mixed number and a one-sentence explanation. |
| Parent/tutor explanation notes | The child is learning that a mixed number is one number made from complete wholes plus a fraction of the next whole. Ask them to point to the wholes before naming the fraction. |

### FR-MIX-02 - Count Unit Fraction Parts in a Mixed Number

| Field | Reference |
| --- | --- |
| Source skill focus summary | Connects a mixed number to the total number of equal unit parts it contains. |
| Tian OS skill name | Count Unit Fraction Parts in a Mixed Number |
| Concept tested | Student converts a mixed number into a count of unit fractions, such as counting how many fourths are in `2 1/4`. |
| Prerequisite | Understand that each whole contains a fixed number of unit parts equal to the denominator. |
| Question template types | "How many thirds/fourths/fifths are in this amount?"; fill total unit parts; interpret a story quantity as unit fractions; model-to-count questions. |
| Common misconceptions | Counts only the visible fractional part; adds denominator and numerator without multiplying the wholes; changes the denominator after counting; forgets that every whole has the same number of parts. |
| Remediation strategy | Use repeated groups: each whole contributes one full group of denominator-sized parts, then add the leftover numerator. |
| Recheck pattern | Present a mixed number with a different denominator and require the total count of unit fractions plus the calculation used. |
| Parent/tutor explanation notes | This is the foundation for changing mixed numbers into improper fractions. Listen for "each whole has..." before the child calculates. |

### FR-MIX-03 - Simplify the Fractional Part of a Mixed Number

| Field | Reference |
| --- | --- |
| Source skill focus summary | Reduces the fractional part of a mixed number while preserving the whole-number part. |
| Tian OS skill name | Simplify the Fractional Part of a Mixed Number |
| Concept tested | Student simplifies the fraction in a mixed number using common factors and keeps the whole-number part unchanged. |
| Prerequisite | Find common factors and simplify proper fractions. |
| Question template types | Simplify a mixed number; fill missing numerator and denominator after reduction; identify equivalent mixed numbers; choose simplest form. |
| Common misconceptions | Simplifies the whole-number part; divides numerator and denominator by different numbers; stops before simplest form; changes the mixed number into an unrelated fraction. |
| Remediation strategy | Cover the whole-number part temporarily, simplify only the fractional part, then restore the whole-number part and compare value. |
| Recheck pattern | Give a mixed number with a reducible fractional part and ask for simplest form plus the common factor used. |
| Parent/tutor explanation notes | The whole number is not being reduced. The child should focus on whether the fraction after the whole number can be written in smaller equivalent terms. |

### FR-MIX-04 - Place Mixed Numbers on a Number Line

| Field | Reference |
| --- | --- |
| Source skill focus summary | Uses position and interval reasoning to show mixed numbers between whole numbers. |
| Tian OS skill name | Place Mixed Numbers on a Number Line |
| Concept tested | Student locates a mixed number between two whole numbers by partitioning the interval into denominator-sized equal parts. |
| Prerequisite | Read number lines, count equal intervals, and understand mixed-number parts. |
| Question template types | Mark a mixed number on a number line; read a point as a mixed number; choose the interval containing a mixed number; complete missing tick labels. |
| Common misconceptions | Starts counting fractional parts from zero instead of the whole-number anchor; uses unequal intervals; treats denominator as the tick label; places the fraction before the whole. |
| Remediation strategy | Anchor first at the whole number, draw only the next interval, split that interval into equal parts, then count forward. |
| Recheck pattern | Use a number line with unlabeled ticks between two consecutive whole numbers and ask the student to identify or place a mixed number. |
| Parent/tutor explanation notes | This checks whether the child sees mixed numbers as positions, not just symbols. Ask "between which two whole numbers does it sit?" |

### FR-IMP-01 - Understand Improper Fractions as More Than One Whole

| Field | Reference |
| --- | --- |
| Source skill focus summary | Represents quantities greater than one whole as fractions whose numerator is at least the denominator. |
| Tian OS skill name | Understand Improper Fractions as More Than One Whole |
| Concept tested | Student recognizes that an improper fraction counts unit parts across one or more wholes. |
| Prerequisite | Count unit fractions and understand one whole as denominator-over-denominator. |
| Question template types | Match improper fraction to area model; count shaded unit parts; identify whether a fraction is less than, equal to, or greater than one; write an improper fraction from a model. |
| Common misconceptions | Thinks all fractions must be less than one; treats numerator greater than denominator as invalid; counts whole objects rather than unit parts; reverses numerator and denominator. |
| Remediation strategy | Build one whole as `d/d`, then add extra unit parts. Have the student count all equal parts aloud before writing the numerator. |
| Recheck pattern | Show several complete wholes plus a partial whole and ask for the improper fraction represented. |
| Parent/tutor explanation notes | An improper fraction is still a valid fraction. It tells how many equal parts there are in total, even when that total passes one whole. |

### FR-IMP-02 - Convert Mixed Numbers to Improper Fractions

| Field | Reference |
| --- | --- |
| Source skill focus summary | Changes a whole-plus-part form into one total count of equal fractional parts. |
| Tian OS skill name | Convert Mixed Numbers to Improper Fractions |
| Concept tested | Student uses `(whole number x denominator) + numerator` to find the total numerator while keeping the denominator. |
| Prerequisite | Count unit fraction parts in a mixed number and multiply whole-number groups. |
| Question template types | Convert symbolic mixed numbers; complete missing numerator; convert story quantities into improper fractions; explain the calculation from a model. |
| Common misconceptions | Adds whole, numerator, and denominator; changes the denominator; multiplies numerator by denominator; forgets to add the leftover numerator. |
| Remediation strategy | Write the conversion as grouped unit parts: full groups from wholes plus leftover parts. Connect each step to a model before using the shortcut. |
| Recheck pattern | Convert a mixed number with denominator 3, 4, 5, or 6 and require either a model sketch or grouped calculation. |
| Parent/tutor explanation notes | The denominator stays because the size of each part does not change. Only the count of parts changes. |

### FR-IMP-03 - Convert Improper Fractions to Mixed Numbers

| Field | Reference |
| --- | --- |
| Source skill focus summary | Regroups an improper fraction into complete wholes and a remaining fractional part. |
| Tian OS skill name | Convert Improper Fractions to Mixed Numbers |
| Concept tested | Student divides numerator by denominator to find complete wholes and uses the remainder as the fractional numerator. |
| Prerequisite | Understand division with remainders and one whole as denominator-over-denominator. |
| Question template types | Convert improper fractions; fill quotient and remainder; model grouping into wholes; choose the equivalent mixed number. |
| Common misconceptions | Puts the quotient over the denominator; uses the remainder as the denominator; ignores zero remainder cases; rounds the quotient. |
| Remediation strategy | Group the numerator into sets of denominator-sized wholes. The number of full groups is the whole number, and leftover parts become the numerator. |
| Recheck pattern | Convert an improper fraction with a nonzero remainder and explain what the quotient and remainder mean. |
| Parent/tutor explanation notes | The child is regrouping parts into wholes. Ask "how many full wholes can we make, and what is left?" |

### FR-IMP-04 - Match Equivalent Mixed and Improper Forms

| Field | Reference |
| --- | --- |
| Source skill focus summary | Connects visual, mixed-number, and improper-fraction representations of the same amount. |
| Tian OS skill name | Match Equivalent Mixed and Improper Forms |
| Concept tested | Student recognizes equivalent representations across symbols, models, and short contexts. |
| Prerequisite | Convert in both directions between mixed numbers and improper fractions. |
| Question template types | Match cards; choose all equivalent forms; complete a representation table; detect a wrong conversion. |
| Common misconceptions | Believes mixed and improper forms are different values; matches by similar digits only; does not check denominator consistency; misses simplified equivalents. |
| Remediation strategy | Use a three-column organizer: model, mixed number, improper fraction. Require the student to verify each representation by counting unit parts. |
| Recheck pattern | Give one representation and ask for the other two, including one distractor that shares digits but not value. |
| Parent/tutor explanation notes | This skill checks flexibility. The child should be able to move between forms without changing the amount. |

### FR-CMP-01 - Compare Mixed Numbers with Like Denominators

| Field | Reference |
| --- | --- |
| Source skill focus summary | Compares mixed numbers by considering whole-number parts and then fractional parts when needed. |
| Tian OS skill name | Compare Mixed Numbers with Like Denominators |
| Concept tested | Student decides which mixed number is greater when denominators match or whole-number parts clearly differ. |
| Prerequisite | Understand mixed-number structure and compare proper fractions with the same denominator. |
| Question template types | Choose greater/lesser mixed number; fill inequality symbol; compare story quantities; explain using whole part then fraction part. |
| Common misconceptions | Compares only numerators; ignores whole-number parts; reverses inequality symbols; assumes larger denominator means larger value. |
| Remediation strategy | First compare whole-number parts. If those match, compare the fractional numerators because the part size is the same. |
| Recheck pattern | Provide pairs where one has a larger whole part and pairs where the whole part is equal but numerator differs. |
| Parent/tutor explanation notes | Encourage a two-step comparison: whole numbers first, fractional parts second. This prevents overusing conversion when it is not needed. |

### FR-CMP-02 - Compare Improper Fractions with Common Denominators

| Field | Reference |
| --- | --- |
| Source skill focus summary | Compares improper fractions after making denominators match or when denominators already match. |
| Tian OS skill name | Compare Improper Fractions with Common Denominators |
| Concept tested | Student compares improper fractions by reasoning about equal-sized parts and numerator size. |
| Prerequisite | Equivalent fractions, common denominators, and improper-fraction meaning. |
| Question template types | Compare improper fractions; complete equivalent fractions before comparing; fill inequality symbol; select the larger amount from two models. |
| Common misconceptions | Chooses the fraction with the smaller denominator automatically; compares denominators after common-denominator conversion; makes only one fraction equivalent; loses track of original value. |
| Remediation strategy | State the part size before comparing. If part sizes differ, convert both to a shared denominator, then compare counts of same-sized parts. |
| Recheck pattern | Give two improper fractions with unlike denominators and require a common-denominator comparison. |
| Parent/tutor explanation notes | The child is learning to compare fairly by using the same-sized parts. Ask them to show how both fractions were rewritten before deciding. |

### FR-CMP-03 - Compare Mixed Numbers and Improper Fractions

| Field | Reference |
| --- | --- |
| Source skill focus summary | Compares values written in different forms by converting to a shared representation. |
| Tian OS skill name | Compare Mixed Numbers and Improper Fractions |
| Concept tested | Student compares one mixed number and one improper fraction by converting one or both forms, then using equivalent fractions or mixed-number reasoning. |
| Prerequisite | Convert mixed numbers and improper fractions in both directions; compare fractions with common denominators. |
| Question template types | Compare mixed number vs improper fraction; choose a conversion method; fill inequality symbol; identify an efficient comparison route. |
| Common misconceptions | Compares visible whole number to numerator; converts only one value and compares unlike forms; changes value during conversion; uses the inequality symbol backward. |
| Remediation strategy | Let the student choose one comparison lane: both improper fractions or both mixed numbers. Then verify with approximate size before finalizing the symbol. |
| Recheck pattern | Present one mixed number and one improper fraction close in value; require conversion and an inequality statement. |
| Parent/tutor explanation notes | Different forms can describe the same kind of quantity. The comparison is fair only after both numbers are interpreted in a compatible way. |

### FR-CMP-04 - Order Mixed and Improper Fractions

| Field | Reference |
| --- | --- |
| Source skill focus summary | Arranges several mixed or improper fractions by size using common denominators, converted forms, or number-line reasoning. |
| Tian OS skill name | Order Mixed and Improper Fractions |
| Concept tested | Student orders three or more values that may include mixed numbers, improper fractions, and whole-number equivalents. |
| Prerequisite | Compare pairs of mixed/improper fractions, find common denominators, and use inequality symbols. |
| Question template types | Arrange values from least to greatest; place values on a number line; identify the greatest or smallest; repair an incorrectly ordered list. |
| Common misconceptions | Orders by numerator only; treats whole-number equivalents as separate categories; does not use a common comparison form; confuses increasing and decreasing order. |
| Remediation strategy | Convert all values into one chosen form, annotate approximate size, then order. Use a number line for close values. |
| Recheck pattern | Ask the student to order four values with mixed, improper, and whole-number forms, then justify the first and last positions. |
| Parent/tutor explanation notes | This is a synthesis skill. The child must choose a strategy, keep values equivalent, and compare several numbers consistently. |
