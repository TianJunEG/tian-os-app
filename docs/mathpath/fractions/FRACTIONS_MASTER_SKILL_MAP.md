# Fractions Master Skill Map

Status: reference map  
Scope: Tian OS MathPath Fractions

## Purpose

This document converts the current `F001`-`F026` Fractions reporting anchors into a teachable micro-skill map for future diagnostics, remediation, question generation, model drawing, and parent/tutor dashboards.

This is not a runtime content file. It should not be used to copy third-party questions or diagrams. All production Tian OS questions, diagrams, and explanations must be original.

## Relationship to `F001`-`F026`

The current `F001`-`F026` skills remain stable pilot reporting anchors. The micro-skills below sit underneath those anchors so that broad skills can be diagnosed and remediated precisely.

Recommended hierarchy:

```text
F001-F026 reporting anchor
→ Fractions stage
→ Teachable micro-skill
→ Question family
→ Generated question
→ Misconception tag
→ Remediation and recheck
```

## Seven-stage progression

| Stage | Purpose | Main anchors |
|---|---|---|
| Fractions I: Meaning and Models | Build stable meaning of fractions before symbolic manipulation. | F001-F005 |
| Fractions II: Comparison and Equivalence | Develop size reasoning, equivalence, ordering, and simplest form. | F006-F012 |
| Fractions III: Mixed Numbers and Conversion | Connect quantities greater than one to mixed/improper notation. | F013-F015 |
| Fractions IV: Operations | Add, subtract, multiply, and divide fractions with answer-form checks. | F016-F022 |
| Fractions V: Fraction of Quantity and Model Drawing | Connect fraction operations to quantities and bar models. | F020, F023, F024 |
| Fractions VI: Word Problems and Heuristics | Separate problem schemas from arithmetic procedures. | F023, F024 |
| Fractions VII: Exam Applications and Mastery | Consolidate mixed-format and exam-style fraction applications. | F025, F026 |

## Remediation pattern

Each micro-skill should eventually connect to:

1. a diagnostic item,
2. an error-specific misconception tag,
3. a short remediation explanation,
4. a scaffolded recheck item,
5. an adult-facing parent/tutor note, and
6. a working-evidence expectation where model drawing is required.

## Question generation rules

- Use original values, contexts, names, and diagrams.
- Do not copy third-party sample questions or diagrams.
- Keep answer-form requirements explicit: fraction, mixed number, simplest form, whole number, unit, or explanation.
- Generate misconception-trap distractors deliberately, especially for denominator errors, answer-form mismatch, remainder errors, and weak model drawing.
- For model-drawing skills, require visible working evidence before treating the item as mastery-quality.
