## Scope

Fractions II is mapped as an addition and subtraction unit for students who already understand fraction size, equivalent fractions, improper fractions, and mixed numbers. The sequence moves from direct fraction computation to word-problem reasoning and two-step problem solving.

## FR-ADD-01 - Add like fractions with sum greater than one whole

### Tian OS skill ID

`FR-ADD-01`

### Tian OS skill title

Add like fractions with sum greater than one whole

### Source skill focus summary

Students add fractions with the same denominator and express totals that pass one whole.

### Concept tested

Students add numerators when denominators are the same, identify when the sum is improper, and convert the result to a mixed number when requested.

### Prerequisite skills

- Understand numerator and denominator roles
- Add like fractions within one whole
- Recognize improper fractions
- Convert improper fractions to mixed numbers
- Simplify fractional parts

### Expected answer form

- Improper fraction
- Mixed number
- Mixed number in simplest form
- Short written explanation of whole groups and leftover parts

### Original Tian OS template examples

1. Add two like fractions where the numerator sum is greater than the denominator.
2. Convert the improper result into a mixed number.
3. Choose the correct mixed-number answer from close distractors.
4. Explain how many complete wholes and remaining parts are in the sum.

### Common misconceptions

- Adds denominators as well as numerators
- Leaves an improper fraction when mixed-number form is required
- Converts the improper fraction incorrectly
- Does not simplify the fractional part of the mixed number

### Misconception tags

- `adds_denominators`
- `does_not_convert_improper`
- `wrong_mixed_number_conversion`
- `not_simplified`

### Remediation strategy

Use a visual or unit-part model to show that the denominator names the size of each part. Add only the counts of parts, then group denominator-sized sets into wholes.

### Recheck pattern

Give a like-denominator addition problem with a different denominator and require the final answer as a mixed number in simplest form.

### Parent/tutor explanation notes

The child is learning that fractions can add up to more than one whole. Ask them to count the parts first, then regroup those parts into wholes.

### Suggested difficulty progression

1. Sum is just over one whole and already in simplest form.
2. Sum is more than one whole and requires mixed-number conversion.
3. Sum requires mixed-number conversion and simplification.
4. Student must explain the regrouping process in words.

## FR-ADD-02 - Add unlike fractions using common denominators

### Tian OS skill ID

`FR-ADD-02`

### Tian OS skill title

Add unlike fractions using common denominators

### Source skill focus summary

Students add fractions with different denominators by rewriting them as equivalent fractions with a shared denominator.

### Concept tested

Students find a common denominator, create equivalent fractions correctly, add the numerators, and simplify or convert the final sum when needed.

### Prerequisite skills

- Equivalent fractions
- Common multiples
- Add like fractions
- Simplify fractions
- Convert improper fractions to mixed numbers

### Expected answer form

- Proper fraction in simplest form
- Improper fraction
- Mixed number in simplest form
- Work showing equivalent fractions before addition

### Original Tian OS template examples

1. Add two proper fractions with unlike denominators using a common denominator.
2. Fill in missing equivalent-fraction numerators before adding.
3. Add unlike fractions where the sum is greater than one.
4. Choose the lowest common denominator from several options before solving.

### Common misconceptions

- Adds numerators and denominators directly
- Uses only one denominator without converting both fractions
- Chooses an incorrect common multiple
- Multiplies numerator or denominator inconsistently
- Does not simplify the final answer

### Misconception tags

- `adds_denominators`
- `no_common_denominator`
- `wrong_common_multiple`
- `incorrect_equivalent_fraction`
- `not_simplified`
- `does_not_convert_improper`

### Remediation strategy

Make the "same-sized parts" idea explicit. Have the student rewrite both fractions with the same denominator, check that each equivalent fraction has the same value as the original, then add only the numerators.

### Recheck pattern

Give two unlike fractions with denominators that have a manageable common multiple. Require equivalent-fraction setup and final simplest form.

### Parent/tutor explanation notes

The child is learning to make the parts the same size before adding. Ask them to show how each fraction changed into an equivalent fraction.

### Suggested difficulty progression

1. One denominator is a multiple of the other.
2. Denominators need a shared multiple that is not one of the original denominators.
3. Sum requires simplification.
4. Sum requires conversion to mixed-number form.

## FR-SUB-01 - Subtract unlike fractions using common denominators

### Tian OS skill ID

`FR-SUB-01`

### Tian OS skill title

Subtract unlike fractions using common denominators

### Source skill focus summary

Students subtract fractions with different denominators after converting them to equivalent fractions with the same denominator.

### Concept tested

Students find a common denominator, rewrite both fractions fairly, subtract numerators, and simplify the difference.

### Prerequisite skills

- Equivalent fractions
- Common denominators
- Subtract like fractions
- Simplify fractions
- Compare fraction sizes before subtracting

### Expected answer form

- Proper fraction in simplest form
- Difference shown after equivalent-fraction conversion
- Short explanation of why a common denominator was needed

### Original Tian OS template examples

1. Subtract two unlike proper fractions after rewriting both with a common denominator.
2. Complete missing equivalent-fraction values and then subtract.
3. Choose the correct subtraction result from distractors that use addition or wrong denominators.
4. Explain why the larger fraction must be identified before subtracting.

### Common misconceptions

- Subtracts denominators as well as numerators
- Rewrites only one fraction
- Uses a wrong common multiple
- Subtracts in the wrong order
- Leaves a reducible answer

### Misconception tags

- `adds_denominators`
- `no_common_denominator`
- `wrong_common_multiple`
- `incorrect_equivalent_fraction`
- `wrong_operation_add_subtract`
- `not_simplified`

### Remediation strategy

Use a same-sized-parts model. First ask whether the fractions have the same unit size. If not, rewrite both. Then subtract counts of parts only after the units match.

### Recheck pattern

Give a subtraction problem with unlike denominators and require the student to write both equivalent fractions before subtracting.

### Parent/tutor explanation notes

Subtraction needs equal-sized parts just like addition. The child should not subtract until both denominators match.

### Suggested difficulty progression

1. One denominator is a multiple of the other.
2. Denominators require a new shared multiple.
3. Result needs simplification.
4. Problem includes distractors that tempt addition or denominator subtraction.

## FR-SUB-02 - Subtract a fraction from a whole number

### Tian OS skill ID

`FR-SUB-02`

### Tian OS skill title

Subtract a fraction from a whole number

### Source skill focus summary

Students subtract a fractional amount from one or more wholes by renaming the whole number as fractional parts.

### Concept tested

Students regroup a whole number into denominator-sized parts, subtract the fraction, and express the remaining amount correctly.

### Prerequisite skills

- Understand one whole as denominator-over-denominator
- Convert whole numbers to equivalent fractions
- Subtract like fractions
- Simplify fractions
- Convert improper fractions and mixed numbers

### Expected answer form

- Proper fraction
- Mixed number
- Mixed number or fraction in simplest form
- Work showing the whole renamed as fractional parts

### Original Tian OS template examples

1. Subtract a proper fraction from 1 whole.
2. Subtract a proper fraction from a whole number greater than 1.
3. Rename one whole inside a mixed amount and subtract.
4. Explain why the whole number can be written using the denominator of the fraction.

### Common misconceptions

- Treats a whole number as denominator 1 and subtracts without regrouping
- Cannot rename one whole as equal fractional parts
- Subtracts numerator from whole number directly
- Gives an answer larger than the starting whole
- Does not simplify the final result

### Misconception tags

- `whole_number_regrouping_error`
- `incorrect_equivalent_fraction`
- `does_not_convert_improper`
- `wrong_mixed_number_conversion`
- `not_simplified`

### Remediation strategy

Rename the whole as a full set of denominator-sized parts. For example, with fourths, one whole becomes four fourths. Subtract the fractional part from that full set, then restore any untouched wholes.

### Recheck pattern

Give a whole-number minus fraction problem with a different denominator. Require the student to show the whole as an equivalent fraction before subtracting.

### Parent/tutor explanation notes

The child is not changing the value of the whole number. They are rewriting it in parts that match the fraction being subtracted.

### Suggested difficulty progression

1. Subtract from 1 whole.
2. Subtract from a whole number greater than 1.
3. Subtract from a mixed number requiring regrouping.
4. Include a word problem where a whole item is partly used.

## FR-ADD-03 - Add three or more fractions

### Tian OS skill ID

`FR-ADD-03`

### Tian OS skill title

Add three or more fractions

### Source skill focus summary

Students add multiple fractions by grouping like denominators or rewriting all terms with a common denominator.

### Concept tested

Students choose an efficient common denominator, add several fractions accurately, and simplify or convert the final total.

### Prerequisite skills

- Add unlike fractions
- Find common multiples
- Create equivalent fractions
- Simplify fractions
- Convert improper fractions to mixed numbers

### Expected answer form

- Proper fraction in simplest form
- Mixed number in simplest form
- Calculation showing all fractions rewritten in compatible form

### Original Tian OS template examples

1. Add three fractions where two already have the same denominator.
2. Add three unlike fractions using a shared denominator.
3. Identify an efficient grouping before adding.
4. Add multiple fractions where the final result must be simplified or converted.

### Common misconceptions

- Adds only the first two fractions and ignores the third
- Converts some fractions but not all
- Chooses a common denominator that does not work for every term
- Makes equivalent-fraction errors
- Stops with an unsimplified improper fraction

### Misconception tags

- `stops_after_first_step`
- `no_common_denominator`
- `wrong_common_multiple`
- `incorrect_equivalent_fraction`
- `does_not_convert_improper`
- `not_simplified`

### Remediation strategy

Have the student list every denominator and choose a denominator that works for all terms. Use a checklist to confirm each fraction was converted before addition.

### Recheck pattern

Give three fractions with at least two unlike denominators. Require a common-denominator setup for every fraction and a final simplest-form answer.

### Parent/tutor explanation notes

This skill checks organization as much as calculation. Encourage the student to account for every fraction before adding.

### Suggested difficulty progression

1. Three fractions where two denominators match.
2. Three fractions where one denominator is a multiple of the others.
3. Three fractions requiring a new shared denominator.
4. Final answer requires simplification and mixed-number conversion.

## FR-WP-ADD-01 - Solve addition fraction word problems

### Tian OS skill ID

`FR-WP-ADD-01`

### Tian OS skill title

Solve addition fraction word problems

### Source skill focus summary

Students interpret joining or combining contexts and add fractional quantities with attention to units.

### Concept tested

Students identify addition language or structure, choose relevant fractions, add them using like or unlike denominator strategies, and report the answer with correct units.

### Prerequisite skills

- Add like and unlike fractions
- Simplify final answers
- Interpret units in word problems
- Use bar models or part-whole diagrams

### Expected answer form

- Fraction or mixed number in simplest form
- Answer with unit label
- Optional bar-model or part-whole setup
- Short explanation of why addition was used

### Original Tian OS template examples

1. Combine two measured amounts from a shared context.
2. Find total distance, mass, volume, or time from two fractional parts.
3. Use a bar model to represent two known parts being joined.
4. Choose the correct operation before calculating.

### Common misconceptions

- Chooses subtraction because the problem includes a comparison phrase
- Ignores measurement units
- Adds denominators
- Misses that both quantities refer to the same whole or unit
- Does not simplify or convert the final answer

### Misconception tags

- `wrong_operation_add_subtract`
- `ignores_units`
- `adds_denominators`
- `no_common_denominator`
- `not_simplified`
- `weak_bar_model_interpretation`

### Remediation strategy

Ask the student to underline the quantities, circle the unit, and draw a "parts joining" bar. Only after the structure is clear should they add the fractions.

### Recheck pattern

Give a fresh joining-context problem with unlike denominators and require the student to state the operation, show the addition, and include the unit.

### Parent/tutor explanation notes

The child should decide the story structure before calculating. Ask, "Are the parts being combined, compared, or taken away?"

### Suggested difficulty progression

1. Two like-denominator quantities in the same unit.
2. Two unlike-denominator quantities in the same unit.
3. Addition result greater than one whole.
4. Context includes extra text or a tempting subtraction phrase.

## FR-WP-SUB-01 - Solve subtraction fraction word problems

### Tian OS skill ID

`FR-WP-SUB-01`

### Tian OS skill title

Solve subtraction fraction word problems

### Source skill focus summary

Students interpret take-away, difference, or remaining-amount contexts and subtract fractional quantities.

### Concept tested

Students identify when subtraction is needed, align units and denominators, subtract accurately, and report the remaining or difference amount.

### Prerequisite skills

- Subtract unlike fractions
- Subtract a fraction from a whole number
- Interpret units
- Represent part-whole relationships with a bar model
- Simplify fractions

### Expected answer form

- Fraction in simplest form
- Mixed number in simplest form
- Answer with unit label
- Work showing common denominator or whole-number regrouping

### Original Tian OS template examples

1. Find how much is left after two fractional amounts are used.
2. Find the difference between two measured fractional quantities.
3. Use a total-minus-known-parts structure.
4. Complete a bar model where the unknown is the remaining part.

### Common misconceptions

- Adds all fractions because multiple quantities appear
- Subtracts in the wrong order
- Ignores whole-number regrouping
- Misses the unit or context of the answer
- Misreads bar-model segments

### Misconception tags

- `wrong_operation_add_subtract`
- `whole_number_regrouping_error`
- `no_common_denominator`
- `ignores_units`
- `weak_bar_model_interpretation`
- `not_simplified`

### Remediation strategy

Have the student identify the starting amount, crossed-out or removed amount, and unknown remainder or difference. Use a bar model to show which segment is missing.

### Recheck pattern

Give a remaining-amount problem where a whole or mixed amount loses a fractional part. Require operation choice, denominator work, and unit label.

### Parent/tutor explanation notes

For subtraction stories, the key is finding the starting amount and what is being removed or compared. Ask the child to label those before solving.

### Suggested difficulty progression

1. Take away a like-denominator fraction.
2. Take away an unlike-denominator fraction.
3. Subtract from one whole or a mixed number.
4. Use a bar model with total and multiple known parts.

## FR-WP-2STEP-01 - Solve two-step addition/subtraction fraction word problems

### Tian OS skill ID

`FR-WP-2STEP-01`

### Tian OS skill title

Solve two-step addition/subtraction fraction word problems

### Source skill focus summary

Students solve contexts that require more than one fraction operation, including working backward or combining known parts before subtracting.

### Concept tested

Students plan a two-step solution, decide the correct operation for each step, keep units consistent, and simplify the final result.

### Prerequisite skills

- Add unlike fractions
- Subtract unlike fractions
- Subtract from whole numbers
- Interpret bar models
- Track units and intermediate results

### Expected answer form

- Fraction or mixed number in simplest form
- Answer with unit label
- Two clearly shown operations
- Optional bar model, table, or working-backward diagram

### Original Tian OS template examples

1. Add two known parts, then subtract from a total.
2. Work backward from a final amount after one addition and one subtraction event.
3. Find a missing part in a multi-segment bar model.
4. Solve a context where one step uses unlike-denominator addition and the next uses subtraction.

### Common misconceptions

- Stops after the first operation
- Uses the same operation for both steps without checking meaning
- Loses track of intermediate units
- Misreads the unknown in a bar model
- Does not simplify the final answer

### Misconception tags

- `stops_after_first_step`
- `wrong_operation_add_subtract`
- `ignores_units`
- `weak_bar_model_interpretation`
- `no_common_denominator`
- `not_simplified`

### Remediation strategy

Use a plan-before-calculate routine: identify what is known, what is unknown, and what must be found first. Have the student write Step 1 and Step 2 labels before doing any arithmetic.

### Recheck pattern

Give a two-step context with one add step and one subtract step. Require a labeled plan, two operations, and a final answer with units.

### Parent/tutor explanation notes

This skill is about mathematical planning. The child may know the arithmetic but still need support deciding which quantity to find first.

### Suggested difficulty progression

1. Add two known fractions, then subtract from one whole.
2. Subtract one fraction, then add another.
3. Work backward from a final mixed amount.
4. Interpret a multi-segment bar model with an unknown part.
