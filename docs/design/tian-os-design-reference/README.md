# Tian OS Design System

Tian OS is the AI-native mastery learning operating system from Tian Jun Education Group.

It unifies adaptive mastery learning, AI diagnostics, fluency training, personalised pathways, revision planning, tutor support, and parent analytics under a single calm, intelligent, premium experience.

Tian OS is not a traditional LMS, worksheet generator, or gamified learning app.

It is designed as:

* a mastery operating system
* a learning intelligence layer
* a calm, focused learning environment
* a unified platform for students, tutors, parents, and schools

---

# Product philosophy

Tian OS is designed around one core idea:

> calm intelligence

The platform should feel:

* focused

# MathPath

MathPath is the flagship learning module inside Tian OS.

MathPath focuses on:

* speed
* accuracy
* fluency
* adaptive progression
* mastery pathways
* AI remediation
* confidence building

MathPath combines:

* Kumon-style fluency and repetition
* IXL-style granular mastery tracking
* AI-native adaptive learning systems
* Singapore MOE curriculum alignment

Students are NOT locked to a single school level.

A student may simultaneously be:

* P6 in multiplication
* P4 in fractions
* P3 in ratios

The system diagnoses mastery per skill and recommends personalised progression pathways.

Questions remain tagged according to MOE syllabus levels while progression remains adaptive.

---

# MathPath learning flow

MathPath follows a structured mastery progression model.

## 1. Placement diagnostics

Determine:

* mastery level
* fluency level
* prerequisite gaps
* confidence level

## 2. Worked examples

Students first observe patterns and structure.

## 3. Guided pattern replication

Students follow structured scaffolds and guided practice.

## 4. Independent mastery

Students solve independently with adaptive difficulty.

## 5. Timed fluency drills

Students develop speed, automaticity, and confidence.

## 6. AI remediation

When students repeatedly struggle:

* misconceptions are identified
* prerequisite skills are reinforced
* scaffolded explanations are generated

## 7. Adaptive recommendations

The system continuously recommends:

* next best skills
* remediation pathways
* fluency drills
* revision priorities

# Content fundamentals

Tian OS speaks like a calm, intelligent coach.

* direct
* quiet
* premium

* exaggerated praise
* excessive celebration
* childish language
* corporate jargon
