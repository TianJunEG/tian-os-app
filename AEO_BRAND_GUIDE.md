# AEO - Tutor Matching Platform
## Brand Identity & Style Guide

### Brand Overview
AEO (Adaptive Education Optimization) is a modern, trustworthy edtech platform connecting students with qualified tutors. The brand reflects professionalism, accessibility, and learning excellence.

---

## Color Palette

### Primary Colors
- **Primary Blue**: #0066CC (Trust, stability, learning)
- **Secondary Teal**: #00A8A8 (Growth, progress, engagement)
- **Accent Emerald**: #10B981 (Success, achievement)

### Secondary Colors
- **Warm Orange**: #FF8C42 (Encouragement, motivation)
- **Deep Navy**: #1F2937 (Text, authority)
- **Light Gray**: #F3F4F6 (Backgrounds, cards)
- **White**: #FFFFFF (Clean, spacious)

### Semantic Colors
- **Success**: #10B981
- **Warning**: #F59E0B
- **Error**: #EF4444
- **Info**: #3B82F6

---

## Typography

### Font Stack
**Headings**: Inter Bold/SemiBold (sans-serif, modern)
**Body**: Inter Regular (clean, readable)
**Monospace**: Fira Code (for code/technical content)

### Font Sizes
- **H1**: 48px / 56px (Landing page hero)
- **H2**: 36px / 44px (Section headers)
- **H3**: 28px / 32px (Subsections)
- **Body**: 16px / 24px (Primary text)
- **Small**: 14px / 20px (Secondary, captions)
- **Tiny**: 12px / 16px (Labels, metadata)

---

## Visual Style

### Icons
- **Style**: Outlined, 2px stroke weight
- **Library**: Lucide React or Heroicons
- **Color**: Inherit from text (Primary Blue for CTAs)

### Spacing
- **Base Unit**: 8px
- **Common**: 8px, 16px, 24px, 32px, 48px, 64px

### Border Radius
- **Small**: 4px (inputs, buttons)
- **Medium**: 8px (cards)
- **Large**: 12px (containers)
- **Full**: 50% (avatars, badges)

### Shadows
- **Light**: 0 1px 2px rgba(0,0,0,0.05)
- **Medium**: 0 4px 12px rgba(0,0,0,0.1)
- **Heavy**: 0 10px 40px rgba(0,0,0,0.15)

---

## Component Library

### Buttons
- **Primary**: Solid #0066CC background, white text
- **Secondary**: Outline #0066CC border, blue text
- **Danger**: Solid #EF4444, white text
- **Success**: Solid #10B981, white text

### Cards
- Background: White or #F3F4F6
- Border: 1px solid #E5E7EB
- Radius: 8px
- Shadow: Light

### Inputs
- Border: 1px solid #D1D5DB
- Focus: 2px solid #0066CC
- Placeholder: #9CA3AF
- Radius: 4px

## Voice & Tone
- **Professional but friendly**: Not stuffy, not casual
- **Encouraging**: Support learning journey
- **Clear & direct**: Simple language, no jargon
- **Inclusive**: Welcoming to all backgrounds

### Example Copy
- ✅ "Find your perfect tutor in 3 minutes"
- ❌ "Leverage AI-powered matching algorithms"
- ✅ "Track progress with live feedback"
- ❌ "Synergistic learning solutions"

## Layout Principles
- Mobile-first responsive design
- Maximum content width: 1200px
- Clear hierarchy with generous whitespace
- Accessible contrast ratios (WCAG AA minimum)
- Keyboard navigation support
